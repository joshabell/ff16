# Cape Cod Frosty Fleet #16

Notice of Race and related materials for FF16, a winter dinghy racing fleet in Beverly, Massachusetts.

## Structure

- `assets/` — shared brand assets (fleet logo)
- `seasons/season-N-YYYY-YYYY/` — one folder per season, containing notice-of-race, etc.ß

## Publishing a Notice of Race

Paste the HTML file's contents into a WordPress Custom HTML block. Before publishing, upload the logo to the site's Media Library and replace the `REPLACE-WITH-LOGO-MEDIA-URL` placeholder in the file with its URL. Preview before publishing.
